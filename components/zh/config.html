locales

组件多语言配置

locales.pdf

  • 类型: PDFLocaleConfig

    interface PDFLocaleData {
  /**
   * PDF 提示文字
   *
   * @description 只有在浏览器不支持嵌入 PDF 且没有提供 PDFJS URL 时才会使用
   * [url] 会被实际 PDF 链接替换
   */
  hint: string;
}

interface PDFLocaleConfig {
  [localePath: string]: PDFLocaleData;
}

  • 必填: 否

PDF 组件国际化配置。
